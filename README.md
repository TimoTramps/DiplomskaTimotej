# sistem-za-naročanje-na-zdravniški-pregled

To je prvi videoposnetek v sklopu vodiča za izdelavo sistema za naročanje na zdravniške preglede.
Spletno mesto, zgrajeno s tehnologijama Node.js in MySQL, vključuje naslednje glavne funkcionalnosti:
- Upravljanje uporabnikov (CRUD), prijava in naročanje na zdravniške preglede.
- Iskanje s pomočjo orodja ElasticSearch.
- Klepetalni robot za Facebook Messenger (nadgrajen s tehnologijo Wit.ai).
